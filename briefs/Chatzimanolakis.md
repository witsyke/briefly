## Summary

The paper proposes OPALITS, a method that combines Bayesian optimal experimental design with an SEIrIuR epidemiological model to decide which location (canton) and day a limited number of COVID-19 test kits should be used on, in order to maximize information gain about unreported infections. The utility function is the expected Kullback-Leibler divergence between posterior and prior parameter distributions given a hypothetical survey, computed via Monte Carlo integration and maximized with a sequential (greedy) optimization scheme to avoid the exponential cost of jointly optimizing many survey locations/times. The approach works both without data (epidemic onset, uniform priors) and with data (later stages, where daily case counts inform the prior via nested-sampling Bayesian inference), and treats spatial correlation as zero across locations but exponentially decaying in time within a location. Applied to Switzerland's 26 cantons across three epidemic phases (onset, lockdown, relaxation/second-wave monitoring), the optimal strategy is shown to yield up to 4x narrower prediction confidence intervals and a markedly different (and by the authors' argument more accurate) estimate of the effective reproduction number compared to non-specific/heuristic testing with the same number of samples. The authors position this as the first method for optimal spatiotemporal (not just spatial) allocation of limited test-kit resources, and release open-source software adaptable to other countries/models.

## Takeaways

- Directly relevant precedent for the project's core problem: this is a working instance of "choose optimal next location AND time under resource constraints" (test kits) in an epidemiological setting, using Bayesian optimal experimental design (BOED) rather than heuristics.
- Utility function is expected KL divergence between posterior and prior of parameters-of-interest, estimated by nested Monte Carlo (eq. 17) — a concrete, reusable formulation for information-gain-based acquisition functions in spatio-temporal active learning.
- Greedy/sequential optimization (eq. 18–21) is used explicitly to sidestep the O((KT)^M) combinatorial blowup of jointly selecting M space-time points — the same scaling issue would arise in any spatio-temporal active-learning setup with a discrete location×time grid, so this greedy approximation (with per-step "marginal gain" tracking) is a candidate baseline/ablation.
- They separate "parameters of interest" (what the design should reduce uncertainty on) from "nuisance parameters" (marginalized out but still propagated) — a useful modeling distinction when defining what "informative" means for a design in a spatio-temporal model with many latent state variables (e.g., per-region initial conditions).
- Covariance structure (eq. 2) assumes independence across locations but exponential temporal decay within a location — a simple, explicit way to encode spatio-temporal correlation in the measurement/noise model, worth comparing against richer spatial correlation structures.
- Diminishing returns are observed empirically (4th survey ~10% of cumulative gain of first three) — suggests the project could report/exploit similar saturation curves to justify stopping criteria for sequential design under budget constraints.
- Limitation to note: their utility optimization is over a fixed discrete grid of locations (administrative units) and days, not continuous space/time — relevant if the project's setting requires continuous spatial selection.
- No comparison to other active-learning acquisition functions (e.g., variance reduction, mutual information with predictive quantities) is given — only KL-based expected information gain vs. non-specific/random testing, which somewhat limits how strong a methodological baseline this is beyond "BOED beats naive testing."
